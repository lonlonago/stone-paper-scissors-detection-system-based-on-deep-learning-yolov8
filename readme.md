# Stone-paper-scissors detection system based on deep learning YOLOv8+

## Body

Based on the advanced YOLOv8 object detection algorithm, this project has developed an efficient and accurate stone-paper-scissors gesture recognition system. The system is trained using a specialized gesture dataset, which includes 6455 training images, 576 validation images, and 304 test images, totaling 7335 labeled images. The system can detect and classify three basic gestures in real-time: paper (Paper), rock (Rock), and scissors (Scissors), with an accuracy level that meets industrial application standards. The system utilizes deep learning techniques to train the model through a large amount of data, enabling it to adapt to different lighting conditions, gesture angles, and background environments, demonstrating strong robustness. In addition to achieving core detection functions, the project has been optimized for practical application scenarios, laying a technical foundation for subsequent human-computer interaction applications.
